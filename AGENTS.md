# AGENTS.md — URL Shortener (Go)

## Commands

```bash
make build          # Build binary to bin/url-shortener
make test           # Run all tests (go test ./... -v -count=1)
make run            # Start server on :8080
make sqlc-generate  # Regenerate internal/store/ from db/queries/*.sql
make fmt            # Format with gofumpt (golangci-lint v2 formatter)
make lint           # Lint with golangci-lint
make check          # fmt → lint → test (run before committing)
```

No CI pipeline. `make check` is the closest thing to one.

## Architecture

Three-layer: **Handler** → **Service** → **Store** (sqlc-generated).

- `cmd/url-shortener/main.go` — entrypoint, wiring, graceful shutdown, migrations
- `internal/handler/` — Chi HTTP handlers + routes
- `internal/service/` — business logic, defines `Store` interface
- `internal/store/` — **generated by sqlc**, do not hand-edit `db.go`, `models.go`, `urls.sql.go`, `querier.go`
- `db/migrations/` — SQLite schema
- `db/queries/` — sqlc SQL definitions (source of truth for generated code)
- `api/` — embedded OpenAPI spec served at `/openapi.yaml`

## CGO Required

`github.com/mattn/go-sqlite3` requires CGO. Build and test will fail without a C compiler.

## sqlc Workflow

SQL → queries live in `db/queries/*.sql`, schema in `db/migrations/`. After changes:

1. Edit `db/queries/*.sql`
2. Run `make sqlc-generate`
3. **Never edit `internal/store/db.go`, `models.go`, `urls.sql.go`, or `querier.go` by hand** — they are overwritten on generate.

## Testing

- **Handler tests** (`internal/handler/`): use testify mocks for the Store interface. No real DB.
- **Service tests** (`internal/service/`): also use testify mocks for Store.
- **Store tests** (`internal/store/`): use real SQLite `:memory:` database. These are integration tests.
- Store ordering tests use `time.Sleep(1100ms)` because SQLite `CURRENT_TIMESTAMP` has second precision — tests need distinct timestamps.
- All tests run with `-count=1` (no cache).
- Run a single test: `go test ./internal/handler/ -run TestHandler_PostShorten_201 -v`

## Routing Gotcha

`/openapi.yaml` is registered as a literal route **before** the wildcard `/{slug}` route. If you reorder routes, `/openapi.yaml` could be swallowed by the wildcard catch-all.

## Environment Variables

| Variable | Default | Purpose |
|----------|---------|---------|
| `LISTEN_ADDR` | `:8080` | Server bind address |
| `BASE_URL` | `http://localhost:8080` | Base URL for generated short links |
| `DB_PATH` | `url-shortener.db` | SQLite database file path |

## Conventions

- Store errors are `sql.ErrNoRows` at the data layer, mapped to sentinel errors (`ErrSlugNotFound`, `ErrInvalidURL`, `ErrURLRequired`) in the service layer.
- Slugs are 5-char alphanumeric via `crypto/rand` with collision retry (up to `maxCollisionRetries` attempts).
- All JSON responses use `application/json` content type, except `/openapi.yaml` which uses `application/x-yaml`.
- Go module: `github.com/url-shortener`, Go 1.22.
- Dependencies: Chi v5, go-sqlite3, testify, go-chi/cors.
