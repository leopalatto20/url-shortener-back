# Design: List All Slugs

## Technical Approach

Additive feature following the existing three-layer pattern: sqlc query → store method → service method → handler → route. No schema changes, no new dependencies. The new `GET /slugs` endpoint returns all registered URLs as a JSON array ordered by creation date (newest first).

## Architecture Decisions

### Decision: Query annotation `:many`

| Option | Tradeoff | Decision |
|--------|----------|----------|
| `:one` with manual iteration | Breaks sqlc pattern, requires raw `db.QueryContext` | Rejected |
| `:many` | sqlc generates slice return, consistent with `:one`/`:exec` | **Selected** |

**Rationale**: `:many` generates a `ListSlugsRow` struct and `([]ListSlugsRow, error)` return — same pattern as `GetStats` with `:one`, different cardinality.

### Decision: Separate `SlugEntry` domain type

| Option | Tradeoff | Decision |
|--------|----------|----------|
| Reuse `*service.URLStats` | Less code, conflates stats vs listing semantics | Rejected |
| New `SlugEntry` type | One extra struct, clean separation | **Selected** |

**Rationale**: Listing and stats have different evolution paths. Codebase already uses separate response types per endpoint (`ShortenResponse`, `StatsResponse`).

### Decision: Route order — static before parameterized

| Option | Tradeoff | Decision |
|--------|----------|----------|
| `/slugs` after `/{slug}` | Chi resolves correctly, but misleading ordering | Rejected |
| `/slugs` before `/{slug}` | Explicit priority | **Selected** |

**Rationale**: Chi prioritizes static segments regardless, but explicit ordering matches existing `POST /shorten` before `GET /{slug}` convention.

### Decision: `make([]T, 0)` for empty response

| Option | Tradeoff | Decision |
|--------|----------|----------|
| `nil` slice | `json.Marshal(nil)` → `null`, violates contract | Rejected |
| `make([]T, 0)` | Guarantees `[]` JSON output | **Selected** |

**Rationale**: Go's `json.Marshal(nil)` produces `null`. Proposal requires `[]`.

## Data Flow

```
GET /slugs
    │
    ▼
Handler.HandleListSlugs
    │  calls svc.ListSlugs(ctx)
    ▼
Service.ListSlugs
    │  calls store.ListSlugs(ctx)
    ▼
Store.ListSlugs
    │  calls q.ListSlugs(ctx)  ← sqlc-generated
    ▼
SQLite: SELECT slug, original_url, click_count, created_at
        FROM urls ORDER BY created_at DESC
    │
    ▼  returns []ListSlugsRow
Store maps → []service.SlugEntry
    │
    ▼  returns []service.SlugEntry
Service passes through
    │
    ▼
Handler maps → []SlugListEntry, json.Marshal → 200 JSON response
```

## Interfaces / Contracts

**sqlc query** (added to `db/queries/urls.sql`):
```sql
-- name: ListSlugs :many
SELECT slug, original_url, click_count, created_at FROM urls
ORDER BY created_at DESC;
```

**Domain type** (in `internal/service/interfaces.go`):
```go
type SlugEntry struct {
    Slug        string    `json:"slug"`
    OriginalURL string    `json:"original_url"`
    ClickCount  int64     `json:"click_count"`
    CreatedAt   time.Time `json:"created_at"`
}
```

**Store interface addition**: `ListSlugs(ctx context.Context) ([]SlugEntry, error)`

**Handler response type** (in `internal/handler/handler.go`):
```go
type SlugListEntry struct {
    Slug        string `json:"slug"`
    OriginalURL string `json:"original_url"`
    ClickCount  int64  `json:"click_count"`
    CreatedAt   string `json:"created_at"`
}
```

Handler maps `time.Time` → RFC3339 string, matching `StatsResponse.CreatedAt` pattern.
